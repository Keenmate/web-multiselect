tab-behavior

Targeted by e2e/tab-behavior.spec.ts. A form-like column: plain inputs between pickers so Tab / Shift+Tab traverse them. Events are recorded per picker in window.__events[id].

single, default (select-focused, search cleared on close)
single, tab-behavior="select-navigated"
single, tab-behavior="close"
single, keep-search-on-close="true" + tab-behavior="close"
multi, default (close, search kept)
multi, tab-behavior="select-focused"
single, 50 options, Item 30 selected (open starts at the value)
single, 2000 options, virtual scroll, Item 1500 selected
