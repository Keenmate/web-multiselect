ACTION BUTTONS
==============

CRITICAL: Buttons in the dropdown header/footer for bulk actions (core action items)
- Built-in: 'select-all', 'clear-all' (string shorthand or { action: 'select-all' })
- Custom: { id: 'export', text, icon, onClick } — identified by `id` (NOT action: 'custom')
- Static or dynamic properties (static value + get*Callback(ctx) that wins when set)
- Every activation fires the `action` event (+ el.onAction); beforeActionCallback can cancel
- Layout modes: nowrap, wrap; position top/bottom; alignment
- NONE render when actionButtons is unset — you must opt in
- Property-only (no attribute)

BUILT-IN ACTIONS
----------------
Select All and Clear All buttons — string shorthand:

select.actionButtons = ['select-all', 'clear-all'];
// Default text comes from labels.selectAll / labels.clearAll

Object form (custom text / tooltip / row …):
select.actionButtons = [
  { action: 'select-all', text: 'Select All' },
  { action: 'clear-all', text: 'Clear All', isDanger: true }
];

Built-ins go through the selection vetoes per option (beforeSelectCallback /
beforeDeselectCallback, ctx.source 'select-all' / 'clear-all'); vetoed options are skipped,
the rest apply in ONE change event.

An onClick on a built-in runs BEFORE the built-in behaviour (it no longer replaces it).

BASIC CUSTOM ACTION
-------------------
Add a custom action button (identified by `id`):

select.actionButtons = [
  {
    id: 'custom-action',
    text: 'My Action',
    onClick: (detail) => {
      console.log('Action clicked', detail.id, detail.selectedValues);
    }
  }
];

ACTION PROPERTIES
-----------------
Static properties (MultiSelectActionItem):

{
  action?: 'select-all' | 'clear-all', // Built-in; omit for a custom item
  id?: string,                // Identifies a custom item; reported in the `action` event
  text?: string,              // Button text — PLAIN TEXT (not HTML)
  icon?: string,              // Glyph / emoji / text — inserted as text
  cssClass?: string,          // CSS class(es)
  tooltip?: string,           // Hover tooltip
  row?: number,               // 1-based row (default 1); rows stack inward from the panel edge
  isVisible?: boolean,        // Show/hide (default: true)
  isDisabled?: boolean,       // Enable/disable (default: false)
  isDanger?: boolean,         // Destructive styling (.ms__action-btn--danger)
  isActive?: boolean,         // Toggle state → aria-pressed="true" (.ms__action-btn--active)
  onClick?: (detail) => void | Promise<void>   // Awaited; the button is busy meanwhile
}

Dynamic counterparts (each wins over its static field), all take ONE ctx argument:
  getTextCallback(ctx), getIconCallback(ctx), getTooltipCallback(ctx),
  getClassCallback(ctx), getIsVisibleCallback(ctx), getIsDisabledCallback(ctx),
  getIsActiveCallback(ctx)

ctx (ActionContext) = selection snapshot:
  selectedValues, selectedOptions, options, selectedCount, optionCount, isOpen, searchTerm,
  plus controller + element (non-enumerable) and presentation / isFullscreen / isModal.

onClick(detail) receives the `action` event detail = ctx + action ('select-all' |
'clear-all' | 'custom'), id, item (the clicked action item), source ('action-buttons'),
sourceEvent, triggerElement, dataset.

Example with all properties:
select.actionButtons = [
  {
    id: 'export',
    text: 'Export',
    icon: '⬇️',
    cssClass: 'export-button',
    tooltip: 'Export selected items',
    isVisible: true,
    isDisabled: false,
    onClick: ({ selectedOptions }) => exportSelected(selectedOptions)
  }
];

DYNAMIC CALLBACKS
-----------------
Make properties dynamic with callbacks (ctx = selection snapshot):

select.actionButtons = [
  {
    id: 'toggle-all',
    getTextCallback: ({ selectedCount, optionCount }) =>
      selectedCount === optionCount ? 'Deselect All' : 'Select All',
    getIsVisibleCallback: ({ optionCount }) => optionCount > 0,
    getIsDisabledCallback: ({ optionCount }) => optionCount === 0,
    onClick: ({ controller, selectedCount, optionCount }) => {
      if (selectedCount === optionCount) {
        controller.clearAll();
      } else {
        controller.selectAll();
      }
    }
  }
];

VISIBILITY CONTROL
------------------
Show/hide actions dynamically:

Static:
{
  id: 'export',
  text: 'Export',
  isVisible: false,  // Hidden
  onClick: () => {}
}

Dynamic (callback):
{
  id: 'export',
  text: 'Export',
  getIsVisibleCallback: ({ selectedCount }) => selectedCount > 0,
  onClick: () => {}
}

Use cases:
- Show "Export" only when items selected
- Show "Clear" only when selections exist
- Conditional actions based on state

DISABLED STATE
--------------
Enable/disable actions:

Static:
{
  id: 'save',
  text: 'Save',
  isDisabled: true,
  onClick: () => {}
}

Dynamic (callback):
{
  id: 'save',
  text: 'Save',
  getIsDisabledCallback: ({ selectedCount }) => selectedCount === 0 || selectedCount > 10,
  onClick: () => {}
}

Use cases:
- Disable when no selection
- Disable when limit exceeded
- Disable during async operations

TOGGLE (ACTIVE) STATE
---------------------
A button that toggles something renders aria-pressed="true" when active:

let isCompact = false;
{
  id: 'compact',
  text: 'Compact',
  getIsActiveCallback: () => isCompact,
  onClick: ({ controller }) => {
    isCompact = !isCompact;
    controller.refresh();
  }
}

ICONS
-----
Add icons to actions. Text and icon are inserted as TEXT, not HTML — use a glyph, emoji or
short string (an `<i class="fa …">` tag will show literally).

Emoji:
{
  id: 'export',
  text: 'Export',
  icon: '⬇️',
  onClick: () => {}
}

Unicode:
{
  id: 'clear',
  text: 'Clear',
  icon: '✕',  // ✕
  onClick: () => {}
}

Rendered as <span class="ms__action-btn-icon"> + <span class="ms__action-btn-label">;
gap via --ms-action-button-icon-gap.

TOOLTIPS
--------
Show helpful hints:

{
  id: 'export',
  text: 'Export',
  tooltip: 'Export selected items to CSV',
  onClick: () => {}
}

Dynamic tooltip:
{
  id: 'save',
  text: 'Save',
  getTooltipCallback: ({ selectedCount }) =>
    `Save ${selectedCount} selected item${selectedCount !== 1 ? 's' : ''}`,
  onClick: () => {}
}

CSS CLASSES
-----------
Style actions with custom classes:

{
  id: 'delete',
  text: 'Delete',
  isDanger: true,              // built-in destructive styling
  onClick: () => {}
}

Multiple classes:
{
  id: 'export',
  text: 'Export',
  cssClass: 'primary-button large-button',
  onClick: () => {}
}

Dynamic classes:
{
  id: 'save',
  text: 'Save',
  getClassCallback: () => {
    const hasChanges = checkForChanges();
    return hasChanges ? 'primary-button' : 'secondary-button';
  },
  onClick: () => {}
}

LAYOUT MODES
------------
Control action button layout:

Nowrap (default):
<web-multiselect actions-layout="nowrap">
</web-multiselect>
- Single row
- Buttons may overflow
- Horizontal scroll if needed

Wrap:
<web-multiselect actions-layout="wrap">
</web-multiselect>
- Multiple rows if needed
- Better for many actions
- Mobile-friendly

Position / alignment:
<web-multiselect actions-position="bottom" actions-align="right"></web-multiselect>
- actions-position: top (default) | bottom
- actions-align: stretch (default) | left | right | center | space-between

STICKY ACTIONS
--------------
Keep actions visible when scrolling:

<web-multiselect sticky-actions="true">
</web-multiselect>

Behavior:
- Action bar pinned while the option list scrolls
- Better UX for long lists

Disable:
<web-multiselect sticky-actions="false">
</web-multiselect>

ASYNC ACTIONS
-------------
Handle async operations (onClick is awaited; the button is busy meanwhile):

{
  id: 'save',
  text: 'Save',
  onClick: async ({ selectedOptions, controller }) => {
    try {
      const response = await fetch('/api/save', {
        method: 'POST',
        body: JSON.stringify(selectedOptions)
      });

      if (response.ok) {
        controller.showMessage('Saved successfully', { type: 'success' });
      }
    } catch (error) {
      controller.showMessage('Save failed', { type: 'error' });
    }
  }
}

With loading state:
let isSaving = false;

{
  id: 'save',
  getTextCallback: () => isSaving ? 'Saving...' : 'Save',
  getIsDisabledCallback: () => isSaving,
  onClick: async () => {
    isSaving = true;
    await saveData();
    isSaving = false;
  }
}

MULTIPLE ACTIONS
----------------
Common action combinations:

Select All + Clear All:
select.actionButtons = [
  'select-all',
  { action: 'clear-all', getIsVisibleCallback: ({ selectedCount }) => selectedCount > 0 }
];

CRUD operations:
select.actionButtons = [
  {
    id: 'add',
    text: 'Add New',
    icon: '➕',
    onClick: () => openAddDialog()
  },
  {
    id: 'edit',
    text: 'Edit',
    getIsDisabledCallback: ({ selectedCount }) => selectedCount !== 1,
    onClick: ({ selectedOptions }) => editSelected(selectedOptions[0])
  },
  {
    id: 'delete',
    text: 'Delete',
    isDanger: true,
    getIsDisabledCallback: ({ selectedCount }) => selectedCount === 0,
    onClick: ({ selectedOptions }) => deleteSelected(selectedOptions)
  }
];

THE `action` EVENT
------------------
Every activation — built-in or custom button, plus any `data-action` element inside rendered
option content (source 'option', detail.option), badge content (source 'badge') or a
showMessage element (source 'message') — fires the `action` event.

Order: beforeActionCallback → item.onClick → `action` event → built-in behaviour.

// Handle all custom buttons in one place
select.addEventListener('action', (e) => {
  const { action, id, source, selectedValues } = e.detail;
  if (id === 'export') exportValues(selectedValues);
});

// Property twin — receives the DETAIL, not the CustomEvent
select.onAction = (detail) => console.log(detail.action, detail.id, detail.source);

// data-action inside option content fires `action` instead of toggling the row
select.renderOptionContentCallback = ({ item }) =>
  `<span>${item.name}</span> <button data-action="info" data-id="${item.id}">i</button>`;
select.onAction = ({ id, source, option, dataset }) => {
  if (source === 'option') showInfo(option);
};

CONFIRMATION / CANCELLING
-------------------------
beforeActionCallback(detail) → return false to cancel (onClick, the `action` event and the
built-in all skipped). May be async.

select.beforeActionCallback = (detail) => {
  if (detail.action === 'clear-all') {
    return confirm('Clear all selections?') ? undefined : false;
  }
};

Or inside a custom item:
{
  id: 'delete',
  text: 'Delete Selected',
  isDanger: true,
  onClick: ({ selectedOptions, controller }) => {
    if (confirm(`Delete ${selectedOptions.length} item(s)?`)) {
      deleteItems(selectedOptions);
      controller.clearAll();
    }
  }
}

ACTION CONTEXT
--------------
Everything is on the detail — no need to reach back to the element:

{
  id: 'export',
  text: 'Export',
  onClick: ({ selectedOptions, optionCount, searchTerm }) => {
    exportData({
      selected: selectedOptions,
      total: optionCount,
      filter: searchTerm
    });
  }
}

detail.controller is the public facade (also el.controller): selectAll(), clearAll(),
toggleValue(v), selectValue(v), deselectValue(v), setSelected(values), open(), close(),
search(term), clearSearch(), refresh(), showMessage(content, { type, autoHideMs, placement }),
hideMessage(), focus methods …

UPDATING ACTIONS
----------------
Change actions at runtime:

// Add actions
select.actionButtons = [
  { id: 'action1', text: 'Action 1', onClick: () => {} }
];

// Update actions
select.actionButtons = [
  ...select.actionButtons,
  { id: 'action2', text: 'Action 2', onClick: () => {} }
];

// Remove actions
select.actionButtons = select.actionButtons.filter(
  action => action.id !== 'action1'
);

// Clear all actions
select.actionButtons = [];

STYLING ACTIONS
---------------
Style action buttons with CSS variables:

<style>
  web-multiselect {
    --ms-action-button-bg: #f3f4f6;
    --ms-action-button-color: #374151;
    --ms-action-button-bg-hover: #e5e7eb;
    --ms-action-button-border-color: #d1d5db;
    --ms-action-button-danger-color: #dc2626;
    --ms-action-button-active-color: #2563eb;
    --ms-action-button-icon-gap: 0.25rem;
  }
</style>

Or inject styles (single ctx argument):
select.getCustomStylesCallback = (ctx) => `
  .primary-button {
    font-weight: 600;
  }
`;

DISABLING ALL ACTIONS
---------------------
Temporarily disable all actions:

select.actionButtons = select.actionButtons.map(action => ({
  ...(typeof action === 'string' ? { action } : action),
  isDisabled: true
}));

BEST PRACTICES
--------------
✅ Use clear, action-oriented text
✅ Provide tooltips for clarity
✅ Disable actions when not applicable
✅ Hide actions that don't make sense
✅ Confirm destructive actions (beforeActionCallback or confirm in onClick)
✅ Use isDanger for destructive actions
✅ Handle async operations properly
✅ Use icons (glyph/emoji) for better recognition
✅ Test on mobile (wrap mode)

❌ Don't have too many actions (3-5 max)
❌ Don't put HTML in text / icon (inserted as text)
❌ Don't use action: 'custom' — give custom items an `id`
❌ Don't forget error handling
❌ Don't use confusing labels

COMMON PATTERNS
---------------
Select/Deselect All:
{
  id: 'toggle-all',
  getTextCallback: ({ selectedCount, optionCount }) =>
    selectedCount === optionCount ? 'Deselect All' : 'Select All',
  onClick: ({ controller, selectedCount, optionCount }) =>
    selectedCount === optionCount ? controller.clearAll() : controller.selectAll()
}

Export selected:
{
  id: 'export',
  text: 'Export',
  icon: '⬇️',
  getIsDisabledCallback: ({ selectedCount }) => selectedCount === 0,
  onClick: ({ selectedOptions }) => {
    const csv = convertToCSV(selectedOptions);
    downloadFile(csv, 'export.csv');
  }
}
