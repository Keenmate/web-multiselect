CUSTOM RENDERING
================

CRITICAL: Full control over HTML rendering
- renderOptionContentCallback: Dropdown options
- renderBadgeContentCallback: Selected badges
- renderSelectedItemContentCallback: Popover items
- renderSelectedContentCallback: Single-select input text
- Returns HTML string or HTMLElement
- ONE ctx argument: the option is ctx.option, plus rendering state
  (and ctx.controller / ctx.element, non-enumerable)
- A [data-action] element inside option/badge content fires the `action` event

RENDER OPTION CONTENT
---------------------
Customize dropdown option appearance:

select.renderOptionContentCallback = (context) => {
  return `
    <div class="custom-option">
      ${context.option.icon || ''} ${context.option.label}
      ${context.isSelected ? '✓' : ''}
    </div>
  `;
};

Context object (OptionContentRenderContext):
{
  option: T,              // The option
  optionIndex: number,    // Option index in the filtered list
  isSelected: boolean,    // Currently selected
  isFocused: boolean,     // Keyboard focused
  isMatched: boolean,     // Matches search (navigate mode)
  isDisabled: boolean,    // Option disabled
  // tree mode only: isTreeNode, isBranch, isLeaf, childCount, level, depth, path,
  //                 isSelectable, isIndeterminate
  controller, element,    // non-enumerable
  presentation, isFullscreen, isModal
}

RETURN TYPES
------------
Return HTML string:

✅ select.renderOptionContentCallback = ({ option }) => {
  return `<span>${option.label}</span>`;
};

Return HTMLElement:

✅ select.renderOptionContentCallback = ({ option }) => {
  const div = document.createElement('div');
  div.textContent = option.label;
  div.className = 'custom-option';
  return div;
};

IMPORTANT: HTMLElement more secure (no XSS), string more flexible

RENDER BADGE CONTENT
--------------------
Customize selected badge appearance:

select.renderBadgeContentCallback = ({ option, isInPopover }) => {
  if (isInPopover) {
    return `${option.label} — ${option.description}`;
  }
  return option.label;
};

Context object (BadgeContentRenderContext):
{
  option: T,              // The selected option
  displayMode: BadgesDisplayMode, // 'badges' | 'count' | 'compact' | 'partial' | 'none'
  isInPopover: boolean,   // Rendering in popover vs main area
  controller, element,    // non-enumerable
  presentation, isFullscreen, isModal
}

RENDER WHOLE BADGE
------------------
renderBadgeCallback(ctx) replaces the WHOLE pill (not just its content). The component wraps
it in .ms__badge.ms__badge--custom with data-value. Removal is delegated to any inner element
with data-ms-action="remove" (or class ms__badge-remove). Return null/'' to fall back to the
default pill for that item.

select.renderBadgeCallback = ({ option }) => `
  <span class="chip">
    ${option.label}
    <button type="button" data-ms-action="remove" aria-label="Remove">×</button>
  </span>
`;

NOTE: data-action / data-id are reserved for action items — a [data-action] element in badge
content fires the `action` event (source 'badge'), it does NOT remove the badge.

RENDER SELECTED CONTENT
-----------------------
Customize single-select input text:

select.renderSelectedContentCallback = ({ option }) => {
  return `${option.icon || ''} ${option.label}`;
};

IMPORTANT: Returns plain text, not HTML
- Only for single-select mode (multiple="false")
- Displayed in main input field
- No HTML allowed (security)

CONTEXT-AWARE RENDERING
-----------------------
Render differently based on context:

select.renderOptionContentCallback = (context) => {
  if (context.isFocused) {
    return `
      <div class="option-focused">
        <strong>${context.option.label}</strong>
        ${context.option.description}
      </div>
    `;
  }

  if (context.isSelected) {
    return `
      <div class="option-selected">
        ✓ ${context.option.label}
      </div>
    `;
  }

  return `<div>${context.option.label}</div>`;
};

CONDITIONAL RENDERING
---------------------
Show/hide elements based on data:

select.renderOptionContentCallback = (context) => {
  const badge = context.option.isNew ? '<span class="badge-new">NEW</span>' : '';
  const icon = context.option.icon ? `<img src="${context.option.icon}" />` : '';
  const subtitle = context.option.subtitle ? `<div class="subtitle">${context.option.subtitle}</div>` : '';

  return `
    <div class="option">
      ${icon}
      <div class="content">
        <div class="label">${context.option.label} ${badge}</div>
        ${subtitle}
      </div>
      ${context.isSelected ? '<span class="check">✓</span>' : ''}
    </div>
  `;
};

HTMLELEMENT RENDERING
---------------------
Use DOM API instead of HTML strings:

select.renderOptionContentCallback = (context) => {
  const div = document.createElement('div');
  div.className = 'custom-option';

  const icon = document.createElement('span');
  icon.textContent = context.option.icon || '';
  div.appendChild(icon);

  const label = document.createElement('span');
  label.textContent = context.option.label;
  div.appendChild(label);

  if (context.isSelected) {
    const check = document.createElement('span');
    check.textContent = '✓';
    check.className = 'check';
    div.appendChild(check);
  }

  return div;
};

Benefits:
✅ Prevents XSS attacks
✅ Better performance for complex DOM
✅ Type safety

Drawbacks:
❌ More verbose
❌ Harder to read

ESCAPING USER CONTENT
---------------------
Prevent XSS when using HTML strings:

function escapeHtml(text) {
  const div = document.createElement('div');
  div.textContent = text;
  return div.innerHTML;
}

select.renderOptionContentCallback = ({ option }) => {
  const safeLabel = escapeHtml(option.label);
  const safeDescription = escapeHtml(option.description);

  return `
    <div>
      <div>${safeLabel}</div>
      <div>${safeDescription}</div>
    </div>
  `;
};

Or use HTMLElement (automatic escaping):
select.renderOptionContentCallback = ({ option }) => {
  const div = document.createElement('div');
  div.textContent = option.label;  // Automatically escaped
  return div;
};

HIGHLIGHTING SEARCH MATCHES
---------------------------
Highlight matching text:

let searchTerm = '';
select.beforeSearchCallback = ({ term }) => { searchTerm = term; };  // remember the typed term

select.renderOptionContentCallback = ({ option, isMatched }) => {
  if (!isMatched || !searchTerm) {
    return option.label;
  }

  const term = searchTerm.toLowerCase();
  const label = option.label;
  const index = label.toLowerCase().indexOf(term);

  if (index === -1) return label;

  const before = label.substring(0, index);
  const match = label.substring(index, index + term.length);
  const after = label.substring(index + term.length);

  return `${before}<mark>${match}</mark>${after}`;
};

BADGE RENDERING
---------------
Different rendering for badges:

select.renderBadgeContentCallback = ({ option, displayMode, isInPopover }) => {
  // Compact mode: full label on the single visible badge
  if (displayMode === 'compact') {
    return option.label;
  }

  // Popover: Show full details
  if (isInPopover) {
    return `
      <div class="badge-popover">
        ${option.icon} ${option.label}
      </div>
    `;
  }

  // Regular pills: Short form
  return option.code || option.label.substring(0, 3).toUpperCase();
};

ACTION TRIGGERS IN CONTENT
--------------------------
A [data-action] element inside rendered option content fires the `action` event
(source 'option', detail.option = the row's option) and does NOT toggle the row:

select.renderOptionContentCallback = ({ option }) => `
  <span>${option.label}</span>
  <button type="button" data-action="details">ⓘ</button>
`;
select.onAction = ({ action, source, option }) => {
  if (source === 'option' && action === 'details') openDetails(option);
};
// beforeActionCallback(detail) → return false to cancel.

DYNAMIC CONTENT
---------------
Render based on runtime state:

select.renderOptionContentCallback = (context) => {
  const user = getCurrentUser();
  const isOwner = context.option.ownerId === user.id;
  const canEdit = user.permissions.includes('edit');

  return `
    <div class="option">
      ${context.option.label}
      ${isOwner ? '<span class="badge-owner">Owner</span>' : ''}
      ${canEdit ? '<span class="icon-edit">✏️</span>' : ''}
    </div>
  `;
};

PERFORMANCE
-----------
Optimize rendering for large lists:

// ❌ Slow: Complex rendering for every option
select.renderOptionContentCallback = (context) => {
  const data = expensiveCalculation(context.option);
  return `<div>${data}</div>`;
};

// ✅ Fast: Pre-calculate or cache
const cache = new Map();
select.renderOptionContentCallback = (context) => {
  if (!cache.has(context.option.value)) {
    cache.set(context.option.value, expensiveCalculation(context.option));
  }
  return `<div>${cache.get(context.option.value)}</div>`;
};

COMBINING CALLBACKS
-------------------
Use multiple rendering callbacks together:

// Option in dropdown
select.renderOptionContentCallback = (context) => {
  return `
    <div class="dropdown-option">
      ${context.option.icon} ${context.option.label}
    </div>
  `;
};

// Badge in main area
select.renderBadgeContentCallback = (context) => {
  return context.option.code;  // Short form
};

// Item in popover
select.renderSelectedItemContentCallback = ({ option }) => {
  return `
    <div class="popover-item">
      ${option.icon} ${option.label} - ${option.description}
    </div>
  `;
};

// Single-select input
select.renderSelectedContentCallback = ({ option }) => {
  return `${option.icon} ${option.label}`;
};

UPDATING RENDERING
------------------
Change rendering at runtime:

function setCompactMode() {
  select.renderOptionContentCallback = ({ option }) => {
    return option.label.substring(0, 20);
  };
}

function setDetailedMode() {
  select.renderOptionContentCallback = ({ option }) => {
    return `
      <div>
        <div>${option.label}</div>
        <div>${option.description}</div>
      </div>
    `;
  };
}

// Trigger re-render
select.options = [...select.options];

BEST PRACTICES
--------------
✅ Return HTML string for simple rendering
✅ Return HTMLElement for complex DOM or security
✅ Use context for conditional rendering
✅ Escape user content to prevent XSS
✅ Cache expensive calculations
✅ Keep rendering fast (<1ms per option)
✅ Use getCustomStylesCallback for CSS
✅ Test with large datasets

❌ Don't do heavy computation in render callback
❌ Don't forget to escape user content
❌ Don't manipulate Shadow DOM directly
❌ Don't use external CSS (won't apply)
❌ Don't return null/undefined

COMMON PATTERNS
---------------
Simple with icon:
select.renderOptionContentCallback = ({ option }) => {
  return `${option.icon || ''} ${option.label}`;
};

With selection indicator:
select.renderOptionContentCallback = (context) => {
  return `
    <div>
      ${context.isSelected ? '✓ ' : ''}${context.option.label}
    </div>
  `;
};

With subtitle:
select.renderOptionContentCallback = ({ option }) => {
  return `
    <div>
      <div class="label">${option.label}</div>
      <div class="subtitle">${option.subtitle}</div>
    </div>
  `;
};

Badge with initials:
select.renderBadgeContentCallback = ({ option }) => {
  return option.label
    .split(' ')
    .map(w => w[0])
    .join('')
    .toUpperCase();
};
