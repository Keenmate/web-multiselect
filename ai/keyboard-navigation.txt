KEYBOARD NAVIGATION
===================

CRITICAL: Full keyboard accessibility
- Arrow keys for navigation
- Enter to select
- Escape to close
- PageUp/PageDown for quick jumps
- Home/End for first/last
- Type to search/filter
- Works with screen readers

BASIC NAVIGATION
----------------
Arrow keys:

↑ (Up Arrow): Previous option
- Moves focus up one option
- Wraps to last option at top
- Works in open dropdown

↓ (Down Arrow): Next option
- Moves focus down one option
- Wraps to first option at bottom
- Opens dropdown if closed

SELECTION
---------
Enter: Select focused option
- Selects currently focused option
- In multi-select: Toggles selection
- In single-select: Selects and closes
- If dropdown closed: Opens dropdown

Space: Toggle selection (multi-select)
- Toggles focused option
- Keeps dropdown open
- Only in multi-select mode

CLOSING DROPDOWN
----------------
Escape: Close dropdown
- Closes dropdown without selecting
- Returns focus to input
- Preserves current selections
- Clears search if any

Opening (Tab in, click): single-select with a value and no search term starts
the highlight on the selected option (scrolled to the middle), like native <select>;
ArrowUp/Down move from there. Multi-select: no initial highlight.

Tab / Shift+Tab: select per tab-behavior, close, move focus
- tab-behavior="select-focused" (single-select default): selects the highlighted
  option first, including the first match highlighted while typing
  (type "cesky kru", Tab -> Cesky Krumlov selected, select + change fired)
- tab-behavior="select-navigated": only an option moved to with arrows /
  PageUp/PageDown / Home/End (typing resets it)
- tab-behavior="close" (multi-select default): selects nothing
- Never deselects; beforeSelectCallback can veto
- Closes dropdown, focus moves to the next / previous field (not prevented)
- Single-select clears its search on close (keep-search-on-close unset)

QUICK JUMPS
-----------
PageDown: Jump 10 options down
- Moves focus 10 options at once
- Fast navigation in long lists
- Wraps to top if at end

PageUp: Jump 10 options up
- Moves focus 10 options at once
- Fast navigation in long lists
- Wraps to bottom if at start

Home: First option
- Jumps to first option
- Quick way to reach top

End: Last option
- Jumps to last option
- Quick way to reach bottom

SEARCH MODE NAVIGATION
----------------------
Filter mode:

Type: Filter options
- Filters options as you type
- ↑↓: Navigate filtered results
- Enter: Select focused option
- Esc: Clear search and close

Navigate mode:

Type: Highlight matches
- Highlights first matching option
- All options remain visible
- ↑↓: Normal navigation
- Ctrl+↓: Jump to next match
- Ctrl+↑: Jump to previous match

CTRL COMBINATIONS
-----------------
Ctrl+↓: Next match (navigate mode)
- Jumps to next search match
- Cycles through matches
- Only in navigate mode

Ctrl+↑: Previous match (navigate mode)
- Jumps to previous search match
- Cycles through matches
- Only in navigate mode

Ctrl+A: Select all (custom implementation)
- Not built-in
- Can be added via custom handler

FOCUS MANAGEMENT
----------------
Focus states:

Closed dropdown:
- Focus on input field
- ↓ or Enter: Opens dropdown

Open dropdown:
- Focus on search input
- ↑↓: Navigate options
- Enter: Select
- Esc: Close

Focus indicators:
- Visual highlight on focused option
- CSS variable: --ml-option-focus-bg

ACCESSIBILITY
-------------
Screen reader support:

ARIA attributes:
- role="combobox" on input
- role="listbox" on dropdown
- role="option" on options
- aria-selected for selections
- aria-disabled for disabled options

Announcements:
- Selection changes announced
- Focus changes announced
- Search results announced

BADGE REMOVAL
-------------
Remove badge via keyboard:

In main area:
- Tab to badge
- Press Delete or Backspace
- Badge removed
- Focus returns to input

Note: Badge keyboard navigation depends on implementation

WITH GROUPS
-----------
Navigate grouped options:

↑↓: Skip over group headers
- Moves to next/previous option
- Group headers not selectable
- Visual indication of group

Enter on group:
- May collapse/expand (if implemented)
- Or moves to first option in group

DISABLED OPTIONS
----------------
Navigate disabled options:

↑↓: Moves through disabled options
- Disabled options can receive focus
- Visual indication (grayed out)

Enter on disabled:
- No action
- Visual/audio feedback
- Screen reader announces disabled

VIRTUAL SCROLLING
-----------------
Keyboard navigation with virtual scroll:

↑↓: Scroll to show focused item
- Automatically scrolls into view
- Smooth scrolling
- Maintains buffer

PageUp/PageDown: Works normally
- Calculates correct jump
- Scrolls to show focus

Home/End: Instant jump
- Scrolls to top/bottom
- Shows first/last item

CUSTOM KEYBOARD HANDLERS
------------------------
beforeKeydownCallback(ctx) runs BEFORE all built-in keyboard handling. Return false to
suppress the built-in handling of that key (you own preventDefault); return nothing to fall
through to the defaults. Must answer synchronously.

ctx (KeydownContext): event, key, isOpen, searchTerm, focusedIndex, focusedOption,
filteredOptions, selectedValues (real values), plus controller (the public
MultiSelectController — focus methods included) and element.

select.beforeKeydownCallback = ({ event, key, controller }) => {
  // Ctrl+A: Select all
  if (event.ctrlKey && key === 'a') {
    event.preventDefault();
    controller.selectAll();
    return false;            // skip the built-in handling
  }

  // Ctrl+D: Deselect all
  if (event.ctrlKey && key === 'd') {
    event.preventDefault();
    controller.clearAll();
    return false;
  }

  // vim-style navigation
  if (key === 'j') { event.preventDefault(); controller.focusNext(); return false; }
  if (key === 'k') { event.preventDefault(); controller.focusPrevious(); return false; }

  // anything else → built-in handling
};

Controller focus methods: focusNext(), focusPrevious(), focusFirst(), focusLast(),
focusPageUp(), focusPageDown(), focusNextMatch(), focusPreviousMatch(), focusIndex(i),
toggleFocused().

PREVENTING DEFAULT
------------------
Prevent default behavior:

select.beforeKeydownCallback = ({ event, key, isOpen, controller }) => {
  // Open instead of submitting the form on Enter
  if (key === 'Enter' && !isOpen) {
    event.preventDefault();
    controller.open();
    return false;
  }

  // Prevent Tab closing if needed
  if (key === 'Tab') {
    // Custom logic; return false to suppress the built-in Tab behaviour
  }
};

FOCUS TRAPPING
--------------
Keep focus within dropdown:

Useful for modal contexts:

select.beforeKeydownCallback = ({ event, key, isOpen, controller }) => {
  if (key === 'Tab' && isOpen) {
    event.preventDefault();
    // Keep focus in dropdown — cycle through options
    event.shiftKey ? controller.focusPrevious() : controller.focusNext();
    return false;
  }
};

MOBILE KEYBOARD
---------------
Touch keyboard support:

Enter: Select option
- On-screen keyboard
- Works on mobile devices

Arrow navigation:
- May not be available
- Touch scrolling preferred
- Search still works

BROWSER DIFFERENCES
-------------------
Key handling varies:

Chrome/Edge:
- All keys work as expected
- Smooth scrolling

Firefox:
- All keys work
- May need preventDefault in some cases

Safari:
- Most keys work
- Some quirks with Meta key
