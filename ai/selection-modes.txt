SELECTION MODES
===============

CRITICAL: Two distinct modes with different behaviors
- Multi-select (default): multiple="true", returns array
- Single-select: multiple="false", returns single value, auto-closes

MULTI-SELECT MODE (DEFAULT)
---------------------------
Allows selecting multiple options:

<web-multiselect multiple="true">
  <option value="1">Option 1</option>
  <option value="2">Option 2</option>
  <option value="3">Option 3</option>
</web-multiselect>

Or omit (true is default):
<web-multiselect>
  <option value="1">Option 1</option>
</web-multiselect>

Programmatic:
const select = document.querySelector('web-multiselect');
select.multiple = true;

Behavior:
- Checkboxes shown (configurable)
- Dropdown stays open after selection
- Returns array of values
- Multiple badges displayed

SINGLE-SELECT MODE
------------------
Allows selecting only one option:

<web-multiselect multiple="false">
  <option value="1">Option 1</option>
  <option value="2">Option 2</option>
  <option value="3">Option 3</option>
</web-multiselect>

Programmatic:
select.multiple = false;

Behavior:
- No checkboxes
- Dropdown ALWAYS closes after selection (unconditional, not via
  close-on-select — that attribute is a no-op in single mode)
- Returns single value (not array)
- Shows selected value in input field
- Replacing the selection (picking a different item) fires 'select' +
  'change' but NOT 'deselect' for the displaced item — see EVENT
  SEMANTICS section below and events-callbacks.txt

GETTING SELECTED VALUES
------------------------
Multiple ways to retrieve selection:

Method 1: selectedValue - Returns value(s)
const value = select.selectedValue;

Multi-select returns array:
// [1, 2, 3]

Single-select returns single value:
// 1

Method 2: selectedOptions - Returns full option objects
const selected = select.selectedOptions;

Multi-select returns array of objects:
// [
//   { value: 1, label: 'Option 1' },
//   { value: 2, label: 'Option 2' }
// ]

Single-select returns array with one object:
// [{ value: 1, label: 'Option 1' }]

IMPORTANT: selectedOptions always returns array, even in single-select mode

Method 3: Event detail
select.addEventListener('change', (e) => {
  console.log(e.detail.selectedValues);   // Value(s)
  console.log(e.detail.selectedOptions);  // Full objects
});

SETTING SELECTED VALUES
------------------------
Set selection programmatically:

setSelected() method:
select.setSelected([1, 2, 3]);  // Multi-select
select.setSelected([1]);        // Single-select

IMPORTANT: Always pass array, even for single-select

Or set during initialization:
select.options = [
  { value: 1, label: 'Option 1', selected: true },
  { value: 2, label: 'Option 2', selected: true },
  { value: 3, label: 'Option 3' }
];

Or with initial-values attribute:
<web-multiselect initial-values='[1, 2]'>

CLOSE-ON-SELECT
---------------
Control dropdown behavior after selection:

Multi-select with auto-close:
<web-multiselect close-on-select="true">
  <option value="1">Option 1</option>
</web-multiselect>

Programmatic:
select.closeOnSelect = true;

Default behavior:
- Multi-select: false (stays open)
- Single-select: true (always closes, not configurable)

Use case:
- Quick single selection from multi-select
- "Add tags" type interfaces
- Mobile-friendly interfaces

CLEARING SELECTION
------------------
Clear all selected options:

select.setSelected([]);  // SILENT — fires no 'deselect'/'change' events

Or notify with ONE aggregate 'change' (still veto-free):
select.setSelected([], { notify: true });

If listeners must react like a user gesture, use the controller:
select.controller.clearSelection();  // Fires 'deselect' per removed item + one 'change'
                               // beforeDeselectCallback applies per option (source 'clear-selection')

Or add the clear-selection action button (none render unless you opt in):
select.actionButtons = ['clear-selection'];

Listen to change event:
select.addEventListener('change', (e) => {
  if (e.detail.selectedValues.length === 0) {
    console.log('Selection cleared');
  }
});

SELECTING ALL
-------------
Select all options programmatically:

const allValues = select.options.map(opt => opt.value);
select.setSelected(allValues);

Or use select-all action button:
See action-buttons.txt for details

CHECKING IF SELECTED
--------------------
Check if specific value is selected:

const selected = select.selectedValue;

// Multi-select
if (Array.isArray(selected) && selected.includes(1)) {
  console.log('Option 1 is selected');
}

// Single-select
if (selected === 1) {
  console.log('Option 1 is selected');
}

Or check selected property:
const option = select.options.find(opt => opt.value === 1);
if (option?.selected) {
  console.log('Option 1 is selected');
}

SELECTION EVENTS
----------------
Listen to selection changes:

select event (single option):
select.addEventListener('select', (e) => {
  console.log('Selected:', e.detail.option);
  console.log('All selected:', e.detail.selectedOptions);
});

deselect event (single option):
select.addEventListener('deselect', (e) => {
  console.log('Deselected:', e.detail.option);
  console.log('Remaining:', e.detail.selectedOptions);
});

change event (all selections):
select.addEventListener('change', (e) => {
  console.log('Selected options:', e.detail.selectedOptions);
  console.log('Selected values:', e.detail.selectedValues);
});

NOTE: 'change' only fires when the selection set actually changed
(multiselect.ts:1544 — guard on added.length > 0 || removed.length > 0).
Re-picking the already-selected item in single mode fires nothing.

NOTE: Events bubble but are NOT composed (bubbles: true, composed: false) — they are
dispatched on the host and do not escape an enclosing shadow root. Framework delegation (Svelte 5 onchange, React onChange, Vue @change)
works out of the box. WATCH OUT for collisions with native 'change' and
'select' events at form-level / container-level listeners — filter by
e.target. See events-callbacks.txt EVENT BUBBLING section.

EVENT SEMANTICS — SINGLE VS MULTI
---------------------------------
Single-select REPLACEMENT (picking item B while A is selected):
- 'select' (B) + 'change' — A's removal is silent (no 'deselect' for A)

Single-select TOGGLE OFF (clicking the already-selected item):
- 'deselect' + 'change' — selection becomes empty

Multi-select TOGGLE (any direction):
- 'select' OR 'deselect' + 'change' per click

Multi-select SELECT ALL action button / controller.selectAll():
- 'select' per newly-added item + one 'change' (vetoes apply per option)

controller.clearSelection() — programmatic or "Clear All" action:
- 'deselect' per removed item + one 'change' (vetoes apply per option)

setSelected(values) — programmatic:
- SILENT in both modes, veto-free. setSelected(values, { notify: true }) fires one
  'change'. See events-callbacks.txt PROGRAMMATIC SELECTION — WHICH METHODS FIRE EVENTS.

SELECTION LIMITS
----------------
Limit the number of selections with beforeSelectCallback — it runs BEFORE the
selection changes, once per option (also for Select-All / group checkbox, where vetoed
options are skipped and the rest apply). Return false to veto; explain it with
ctx.controller.showMessage (a returned string does NOT veto):

select.beforeSelectCallback = ({ selectedOptions, controller }) => {
  const maxSelections = 3;
  if (selectedOptions.length >= maxSelections) {
    controller.showMessage(`Maximum ${maxSelections} selections allowed`, { type: 'warning' });
    return false;
  }
};

NOTE: the 'select' / 'change' events (and onSelect / onChange) fire AFTER the commit and
cannot cancel — use the before* hooks to veto.

MINIMUM SELECTIONS
------------------
Enforce minimum selections with beforeDeselectCallback:

select.beforeDeselectCallback = ({ selectedOptions, controller }) => {
  const minSelections = 1;
  if (selectedOptions.length <= minSelections) {
    controller.showMessage(`Minimum ${minSelections} selection required`, { type: 'warning' });
    return false;
  }
};

SINGLE-SELECT DISPLAY
---------------------
Customize single-select input display:

select.renderSelectedContentCallback = ({ option }) => {
  return `${option.icon || ''} ${option.label}`;
};

IMPORTANT: Returns plain text, not HTML

Or use display value callback:
select.getDisplayValueCallback = ({ option }) => {
  return option.label.toUpperCase();
};

MULTI-SELECT DISPLAY

Control how badges are displayed:

Set display mode:

CONDITIONAL SELECTION
---------------------
Validate before selection:

select.beforeSelectCallback = ({ option, selectedOptions, controller }) => {
  // Check if already has item from same group
  const sameGroup = selectedOptions.some(s =>
    s.group === option.group && s.value !== option.value
  );

  if (sameGroup) {
    controller.showMessage('Only one per group allowed', { type: 'warning' });
    return false; // Veto
  }

  // Return nothing → selection proceeds
};

DESELECTION HANDLING
--------------------
"Confirm before removal" — beforeDeselectCallback runs BEFORE the option is removed
(ctx.source: 'option' | 'badge' | 'clear-selection' | 'clear' | 'group'). May be async:

select.beforeDeselectCallback = async ({ option }) => {
  if (option.important && !(await confirmDialog(`Remove ${option.label}?`))) {
    return false;   // keep it
  }
};

select.onDeselect = ({ option }) => console.log('Removed:', option);

PROGRAMMATIC SELECTION
----------------------
Select/deselect in code:

Select additional:
const current = select.selectedValue;
select.setSelected([...current, newValue]);

Deselect specific:
const current = select.selectedValue;
const filtered = current.filter(v => v !== valueToRemove);
select.setSelected(filtered);

Toggle selection:
const current = select.selectedValue;
const newValues = current.includes(value)
  ? current.filter(v => v !== value)
  : [...current, value];
select.setSelected(newValues);

INITIAL SELECTION
-----------------
Set selection on page load:

Declarative:
<web-multiselect initial-values='[1, 2]'>
  <option value="1">Option 1</option>
  <option value="2">Option 2</option>
</web-multiselect>

Or with selected attribute:
<option value="1" selected>Option 1</option>

Programmatic:
const select = document.querySelector('web-multiselect');
select.options = [
  { value: 1, label: 'Option 1', selected: true },
  { value: 2, label: 'Option 2' }
];

Or after initialization:
window.addEventListener('DOMContentLoaded', () => {
  const select = document.querySelector('web-multiselect');
  select.setSelected([1, 2]);
});

SELECTION STATE
---------------
Track selection state:

let lastSelection = [];

select.addEventListener('change', (e) => {
  const current = e.detail.selectedValues;

  // Find what changed
  const added = current.filter(v => !lastSelection.includes(v));
  const removed = lastSelection.filter(v => !current.includes(v));

  console.log('Added:', added);
  console.log('Removed:', removed);

  lastSelection = current;
});

SELECTION CALLBACKS
-------------------
Use the on* twins for side effects (they receive the event DETAIL):

select.onSelect = ({ option }) => {
  console.log('Selected:', option);
  // Analytics, logging, etc.
};

select.onDeselect = ({ option }) => {
  console.log('Deselected:', option);
};

select.onChange = ({ selectedOptions }) => {
  console.log('Changed:', selectedOptions);
  // Update related UI, etc.
};

const formData = new FormData(form);
console.log(formData.get('languages')); // JSON array string

See form-integration.txt for details

DISABLED OPTIONS
----------------
Options can be selected but later disabled:

select.options = [
  { value: 1, label: 'Option 1', selected: true },
  { value: 2, label: 'Option 2', disabled: true, selected: true }
];

Disabled but selected options:
- Remain selected
- Cannot be deselected via UI
- Can be deselected programmatically
- Still included in selectedValue

COMPARING MODES
---------------
Multi-select:
✅ Multiple selections
✅ Checkboxes
✅ Stays open
✅ Returns array
✅ Badges displayed

Single-select:
✅ One selection only
✅ No checkboxes
✅ Auto-closes
✅ Returns single value
✅ Shows value in input

BEST PRACTICES
--------------
✅ Use single-select for exclusive choices (country, status)
✅ Use multi-select for tags, categories, filters
✅ Set close-on-select for mobile-friendly multi-select
✅ Validate selections in callbacks
✅ Always handle both select and deselect events
✅ Use selectedValue for form submission
✅ Use selectedOptions for full object access

❌ Don't mix selection modes during runtime
❌ Don't forget single-select returns single value
❌ Don't manipulate selection outside setSelected()
❌ Don't rely on selected property in options array

COMMON PATTERNS
---------------
Single choice (like dropdown):
<web-multiselect multiple="false">
  <option value="en">English</option>
  <option value="es">Spanish</option>
</web-multiselect>

Multiple tags:
<web-multiselect multiple="true">
  <option value="tag1">Tag 1</option>
  <option value="tag2">Tag 2</option>
</web-multiselect>

Quick multi-select:
<web-multiselect
  multiple="true"
  close-on-select="true">
</web-multiselect>

Selection with validation:
select.beforeDeselectCallback = ({ selectedOptions, controller }) => {
  if (selectedOptions.length === 1) {
    controller.showMessage('Please keep at least one option', { type: 'warning' });
    return false;
  }
};
