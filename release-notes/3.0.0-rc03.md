# Web MultiSelect 3.0.0-rc03 — Release Notes

**Released:** 2026-11-15 · **Pre-release** (`npm install @keenmate/web-multiselect@rc`)

These notes cover the changes since **3.0.0-rc02**, the last version on npm. Upgrading from 2.x?
Read the [3.0.0-rc01 notes](3.0.0-rc01.md) first, then [3.0.0-rc02](3.0.0-rc02.md).

This rc moves the dropdown, the selected-items popover and the phone sheets onto
`@keenmate/web-components-core`'s shared overlay and sheet machinery (core rc19 → rc24). Three
things can break rc02 code: the phone sheet bar variables are renamed to `--ms-sheet-*`, messages
use `variant` / `'danger'`, and the five length inputs are validated as CSS lengths. One default
changed: the floating dropdown now closes when the page scrolls.

The exhaustive, per-change list is in
[`CHANGELOG.md`](https://github.com/keenmate/web-multiselect/blob/prod/CHANGELOG.md) (section
3.0.0-rc03); this document is the upgrade guide and the highlights.

## Breaking changes

### Phone sheet bar variables

The top bar of the phone sheets (the fullscreen dropdown and the fullscreen selected-items popover)
is drawn by core's shared sheet chrome, and its variables use core's 19 suffixes — the same as
`--km-sheet-*` and every other Keenmate component. They are unset by default: unset → page-wide
`--km-sheet-*` → core default. Everything else stays `--ms-fullscreen-*`. No aliases.

| Before (rc02) | rc03 |
|---|---|
| `--ms-fullscreen-header-gap` | `--ms-sheet-header-gap` |
| `--ms-fullscreen-header-padding-v` | `--ms-sheet-header-padding-block` |
| `--ms-fullscreen-header-padding-h` | `--ms-sheet-header-padding-inline` |
| `--ms-fullscreen-header-padding` (shorthand) | removed — use the two above |
| `--ms-fullscreen-header-min-height` / `-bg` / `-border` | `--ms-sheet-header-min-height` / `-bg` / `-border` |
| `--ms-fullscreen-title-font-size` / `-font-weight` | `--ms-sheet-title-font-size` / `-font-weight` |
| `--ms-fullscreen-close-size` / `-icon-size` / `-color` | `--ms-sheet-close-size` / `-icon-size` / `-color` |
| `--ms-fullscreen-close-bg` / `-bg-hover` / `-border` | `--ms-sheet-close-bg` / `-bg-hover` / `-border` |
| `--ms-fullscreen-close-border-radius` / `-edge-nudge` | `--ms-sheet-close-border-radius` / `-edge-nudge` |
| — | new: `--ms-sheet-title-color`, `--ms-sheet-close-icon`, `--ms-sheet-close-focus-color` |

### Message variant

`showMessage()` follows the shared naming rulebook: tone is a `variant`, and the red one is
`danger`.

| Before (rc02) | rc03 |
|---|---|
| `showMessage(text, { type: 'error' })` | `showMessage(text, { variant: 'danger' })` |
| `MessageType` | `MessageVariant` |
| `.ms__message--error` | `.ms__message--danger` |
| `--ms-message-error-bg` / `-color` | `--ms-message-danger-bg` / `-color` |

### Length inputs

`dropdown-min-width`, `dropdown-max-width`, `max-height`, `dropdown-width` and
`selected-popover-width` are parsed by core `toCssLength()`:

- a bare number means px (`max-height="300"`);
- any CSS length works (`dropdown-width="20rem"`, `max-height="50dvh"`);
- an invalid length is refused — a warning, an `input-rejected` event, the previous value kept;
- `null` is refused; `undefined` or removing the attribute resets to the default.

## Behaviour changes

### Close on scroll

The floating dropdown now closes when the page or a scroll container around the control scrolls,
like a native `<select>` — a panel left floating over content that has moved away is the usual
complaint. A scroll inside the dropdown never closes it; the fullscreen sheet is unaffected.
Restore the old behaviour with `close-on-scroll="false"` (`shouldCloseOnScroll = false`).

### The selected-items popover on the overlay tree

The selected-items popover now runs on core `createPopover()` like the dropdown: outside click,
Escape and single-active coordination come from core's overlay tree. Opening another overlay of the
same group now closes it.

### Phone Back button

The phone sheets claim their Back history entry through core `claimBackEntry()`. Back still closes
the sheet; any other close gives the entry back, and the page keeps its scroll position.
`history.state` of that entry is now `{ kmBackEntry: true }` (was `{ msOverlay: <id> }`).

### Writing direction

RTL is the effective CSS direction: a nested `dir="ltr"` inside an RTL section stays LTR, and a CSS
`direction: rtl` counts.

## New features

### `beforeScrollCallback`

Gate every scroll the dropdown does on its own — keyboard moves, navigate-mode search, the
single-select reveal on open, and `scrollToIndex` / `scrollToValue` / `scrollToGroup`:

```js
el.beforeScrollCallback = ({ source, options }) =>
  source === 'open' ? false : { ...options, behavior: 'smooth' };
```

Return `false` to skip the scroll (`scrollTo*` still resolve `true`), or a partial
`{ block, behavior }` to replace the defaults.

### Close reasons

The `close` event's `detail.reason` says why: `api`, `toggle`, `escape`, `tab`, `select`,
`outside-click`, `scroll`, `resize`, `overlay`, `parent`, `back`, `close-button`, `disabled`,
`destroy`, `reference-removed`.

### Page-wide custom CSS

```js
window.components = { 'web-multiselect': { customStyles: '.ms__badge { border-radius: 0; }' } };
```

Styles every instance; an instance's own `customStyles` comes after it and wins. An `@import` in
custom CSS is also linked in `<head>`, so icon fonts register (`shouldHoistImports = false` turns
it off).

### Theming

- `--ms-tooltip-width` (`auto`) and `--ms-tooltip-min-width` (`0`) next to `--ms-tooltip-max-width`,
  with option-tooltip twins `--ms-option-tooltip-width` / `-min-width`.
- The field → panel gap is the page token `--base-dropdown-offset` (4px by default).
- `--ms-font-scale-xs` / `-sm` / `-base` and `--ms-tree-indent-scale` — the single entry point for
  the `--base-*` font / indent steps.

## New API

| Surface | What |
|---|---|
| `close-on-scroll` / `shouldCloseOnScroll` | Close the floating dropdown on page scroll (default `true`) |
| `beforeScrollCallback` | Gate / reshape the dropdown's own scrolls |
| `getParentPathCallback`, `getLevelCallback`, `getHasChildrenCallback` | Callback twins of the tree members, taking precedence |
| `close` `detail.reason` | Why the dropdown closed |
| `window.components['web-multiselect'].customStyles` / `.getCustomStylesCallback` | Page-wide custom CSS |
| `BeforeScrollContext`, `MultiSelectScrollSource`, `MultiSelectScrollOptions`, `DropdownCloseReason`, `MessageVariant` | Exported types |

## Visible changes without a migration

- **Phone sheet bar** — the bar, title and ✕ follow core's defaults: a 44px close chip with the
  `--base-icon-close` glyph, the same as every Keenmate phone sheet. The floating selected-items
  popover keeps its compact header.
- **Full-bleed width** — the fullscreen sheet and the message use `100dvw` (was `100vw`).

## Fixes

- **Controller methods on a disabled / readonly control** — `selectAll()`, `clearSelection()`,
  `selectValue()`, `deselectValue()`, `toggleValue()`, `toggleFocused()` were silently ignored;
  calls from code now work (user gestures stay blocked).
- **Safari Backspace** on a read-only input navigated the page Back.
- **Virtual-list jumps** honour `--ms-options-padding` and `scroll-padding`: the last row comes fully
  into view, and `start` / `nearest` / `end` no longer land one padding off.
- **Async results** re-anchor the open dropdown in place (it can flip above) instead of re-creating it.
