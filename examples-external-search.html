External Search (FlexSearch)

Plug a real search engine into searchCallback — the library stays dependency-free

ES01 · Why

The component's built-in search is a plain case-insensitive substring match (String.includes) — deliberately lean, since that covers most multiselects. When you need fuzzy / partial-token / accent-insensitive / ranked matching, don't bloat the library: externalize the whole search via searchCallback and back it with your own engine. Here that engine is FlexSearch (the same indexer @keenmate/web-treeview uses), wrapped in a small batched FlexIndexer (a trimmed port of the treeview indexer) that builds the index off the main thread via requestIdleCallback. FlexSearch is a dev/consumer dependency only — it is never part of the shipped multiselect bundle. 

import { FlexIndexer } from './examples-flex-indexer.js';

const ix = new FlexIndexer();
ix.build(options, (o) => `${o.label} ${o.code}`);   // index the options (batched)
el.options = options;
el.searchCallback = (term) => ix.search(term, 50);   // externalize the whole search

ES02 · Fuzzy & Accent-Insensitive (flat list)

A flat list of cities with accented names. FlexSearch's Charset.Normalize folds accents and tokenize: "full" matches partial tokens anywhere, with results in relevance order. Try zurich → Zürich, sao → São Paulo, krak → Kraków, muenchen/munch → München. The built-in substring search would miss all of these.

ES03 · External Search on a Tree (full ISCO-08)

External search now composes with tree mode: searchCallback returns the matching nodes from the FlexSearch index and the component rebuilds the hierarchy from them, keeping each match's ancestors so indentation stays coherent — the async analogue of the built-in matches-plus-ancestors behaviour. The index here covers each occupation's title, ISCO code, and full breadcrumb, so you can search by any of them (try 2211 non, welder, or health). 619 groups, indexed off the main thread.

Source: International Standard Classification of Occupations, ISCO-08 (© International Labour Organization) — demo data.
