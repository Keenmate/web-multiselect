DA01 · Custom Object Structure

Use your own data structure! Specify which properties to use for value, display, and other fields using valueMember and displayValueMember. 

// Your custom data structure
const users = [
  { userId: 1, fullName: 'John Doe', email: 'john@example.com', role: 'Admin' },
  { userId: 2, fullName: 'Jane Smith', email: 'jane@example.com', role: 'User' },
  ...
];

// Configure which properties to use
multiselect.valueMember = 'userId';
multiselect.displayValueMember = 'fullName';
multiselect.subtitleMember = 'email';
multiselect.options = users;

DA03 · Callbacks for Complex Logic

Use callbacks when you need complex logic to extract values. Callbacks take precedence over members. 

const products = [
  { sku: 'PRD-001', name: 'Laptop', price: 999, inStock: true },
  { sku: 'PRD-002', name: 'Mouse', price: 29, inStock: false },
  ...
];

multiselect.getValueCallback = (item) => item.sku;
multiselect.getDisplayValueCallback = (item) => `${item.name} - $${item.price}`;
multiselect.getDisabledCallback = (item) => !item.inStock; // Disable out of stock
multiselect.options = products;

API01 · Form Integration — JSON Format

API07 · Open / Close API

Drive the dropdown open state from your own code — wizards, "open on step", or custom trigger buttons. Calling open() from a button's own click handler works directly: the component ignores that opening click so it won't immediately re-close.

  • open() - Open the dropdown
  • close() - Close the dropdown
  • toggle() - Toggle the dropdown open/closed
  • isOpen - Boolean property; reading returns the state, assigning true/false opens/closes it
isOpen:
false
const multiselect = document.querySelector('web-multiselect');

multiselect.open();      // Open the dropdown
multiselect.close();     // Close the dropdown
multiselect.toggle();    // Toggle open/closed

multiselect.isOpen;          // → true / false
multiselect.isOpen = true;   // open by assignment
multiselect.isOpen = false;  // close by assignment

DA04 · Async Search / Lookup

Load options dynamically as users type. Perfect for large datasets, API searches, or real-time filtering. 

// searchCallback receives an AbortSignal as its 2nd argument.
// Forward it to fetch — when a newer keystroke supersedes this
// request (or the element is destroyed), the in-flight fetch is
// cancelled instead of racing the newer one.
multiselect.searchCallback = async (searchTerm, signal) => {
    const response = await fetch(`/api/users?search=${searchTerm}`, { signal });
    return await response.json();
};

// Pair with search-debounce="300" to also coalesce keystroke bursts.

DA05 · Cascading Selects (Reactive Options)

Create dependent dropdowns that automatically update! The options property is reactive - setting element.options = newArray triggers automatic re-rendering. Perfect for Organization → Business Unit → Department flows.

Selected Path:
{
  "organization": null,
  "businessUnit": null,
  "department": null
}

Implementation:

const orgSelect = document.querySelector('#cascade-org');
const buSelect = document.querySelector('#cascade-bu');
const deptSelect = document.querySelector('#cascade-dept');

// Initialize first level
orgSelect.options = organizations;

// When organization changes, update business units
orgSelect.addEventListener('change', async (e) => {
    const orgId = e.detail.selectedValues[0];

    if (orgId) {
        // Fetch business units (simulated async)
        const buOptions = await fetchBusinessUnits(orgId);

        // REACTIVE UPDATE - automatically re-renders!
        buSelect.options = buOptions;
        buSelect.setSelected([]);  // Clear previous selection

        // Clear departments
        deptSelect.options = [];
        deptSelect.setSelected([]);
    } else {
        // Organization cleared - reset cascade
        buSelect.options = [];
        deptSelect.options = [];
    }
});

// When business unit changes, update departments
buSelect.addEventListener('change', async (e) => {
    const buId = e.detail.selectedValues[0];

    if (buId) {
        // Fetch departments (simulated async)
        const deptOptions = await fetchDepartments(buId);

        // REACTIVE UPDATE - automatically re-renders!
        deptSelect.options = deptOptions;
        deptSelect.setSelected([]);
    } else {
        deptSelect.options = [];
    }
});

Key Reactive Behaviors:

  • Automatic re-rendering: Setting element.options = newArray triggers UI update
  • Clear dependent selections: Use setSelected([]) to reset child selects
  • Works with async data: Fetch options from API and assign reactively
  • Proper cleanup: Component destroys/recreates picker for clean state
  • Event-driven: Use 'change' events to chain dependencies

Common Use Cases:

  • Country → State → City selection
  • Category → Subcategory → Product filtering
  • Organization → Department → Team hierarchy
  • Master-detail relationships
  • Conditional option loading

API06 · Synchronous options + setSelected

Assign .options and call setSelected(...) on the very next line — no await. The property write coalesces onto a microtask, but the imperative call flushes it, so the pre-set selection renders immediately. Shown for the partial and compact badge modes (the compact composite badge is what previously mis-rendered when the two calls raced). 

const el = document.querySelector('#compact-mode');
el.options = languages;          // reactive write (coalesces on a microtask)
el.setSelected(['js', 'ts', 'py']); // imperative call flushes it synchronously
